ModoCalendar

Démo des 7 modes de sélection

1. Date simple

2. Date + heure (blocks + lock rules)

3. Plage de dates (2 mois, lock rules, min 2 / max 14 nuits)

4. Plage + heures (arrivée/départ, spinner)

5. Dates multiples (max 5)

5. Dates multiples + heures

5b. Date unique + plusieurs créneaux (multiSlot)

5c. Dates multiples + plusieurs créneaux par date (multiSlot)

6. Plage avec presets + dropdown

6b. Presets + dropdown (English)

6c. Time-only (hideCalendar + date fixe)

7. i18n (switch FR ↔ EN)

8. customCSS + customCSSUrls (design system externe)

9. rangeSize: 3 (single-click = 3 jours)

10. dayInfo (puces colorées + tooltip)
